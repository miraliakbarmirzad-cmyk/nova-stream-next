Install NOVA STREAM

Windows / Mac computer: Open NOVA STREAM in Chrome or Microsoft Edge, then use the Install icon in the address bar or the browser menu → Install NOVA STREAM.

Android: Open this website in Chrome, tap the browser menu (⋮), then choose Install app or Add to Home screen.

iPhone: Open this website in Safari, tap Share, then Add to Home Screen and Add.

The app can also run in its own window on a computer. Your installed app uses the same NOVA STREAM account. Internet is needed for streaming and uploads. Previously saved offline videos may remain available in the same browser storage.
